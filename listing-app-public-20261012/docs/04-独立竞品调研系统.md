# 04｜独立竞品调研系统

## 定位与范围

核心代码明确把 COMPETITOR_RESEARCH_STEPS 作为 independent lane：独立 task record、pool、QA state、event stream、版本；不会自动推进 Listing task。步骤目录包含产品基准、种子竞品、扩搜、同款/OEM、不同价格/规格段、Amazon exact match、饱和搜索、数据核验、价格线、采购风险、QA、Excel和归档。

~~~mermaid
flowchart TD
  A[产品基准] --> B[种子竞品]
  B --> C[自动扩搜]
  C --> D[同款/OEM]
  C --> E[低价/同价/高配/成熟竞品]
  D --> F[Amazon完全同款]
  E --> G[饱和搜索]
  F --> G
  G --> H[参数/价格/评论/销量核验]
  H --> I[价格线]
  I --> J[采购风险]
  J --> K[采购动作池]
  K --> L[调研QA]
  L --> M[调研Excel]
  M --> N[归档]
~~~

图示表示代码目录中的步骤，不证明每个阶段都已连接真实executor。应逐项核验注册、输入合同、外部Provider evidence和QA。

## 与 Listing 主线隔离

- 调研候选若进入 SOP08，仍须走Listing主线身份去重、证据验证和分类。
- 竞品价格、参数和买家意见不能转写为自有商品事实。
- 采购风险/采购动作不是文案生成的自动副作用。
- 两条流程的task、事件、版本和QA不能交叉引用。

## QA建议

每个候选检查身份与canonical URL、来源/时间、ref可读性、未知字段语义、product ID/EAN/URL去重，并把事实、推断、未验证内容分开。

## 限制

公开源快照包含核心流程目录和创建/查询接口，但该调研工作线的所有业务executor/输出模板并不都在公开whitelist中。不得称其为可从公开仓库完整复建的独立调研产品。
